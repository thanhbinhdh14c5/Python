DO AN QUAN LY SINH VIEN

CAU TRUC
- csdl_sinhvien.py: tao va xu ly co so du lieu SQLite.
- ung_dung_sinhvien.py: giao dien quan ly sinh vien bang Tkinter.
- quanly_sinhvien.db: co so du lieu mau.
- dist\QuanLySinhVien\QuanLySinhVien.exe: ung dung Windows da dong goi.

CHAY TU MA NGUON
    python ung_dung_sinhvien.py

DONG GOI LAI
Cai thu vien:
    python -m pip install -r requirements-build.txt

Sau do chay build.bat. Thu muc dist\QuanLySinhVien co the chay tren Windows
ma khong can cai Python. Khi chay EXE, database nam canh file EXE.

Chuong trinh ho tro them, cap nhat, xoa, tim kiem, loc theo lop, thong ke
va bieu do diem trung binh theo lop.
